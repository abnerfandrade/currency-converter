# Conversor de moedas - Desafio da formação Go da Rocketseat

Converte um valor em reais (BRL) para outra moeda usando as cotações de `rates.json`.

## Como executar

Na pasta do projeto, execute:

```bash
./convert 100 USD
```

O primeiro argumento é o valor em reais; o segundo é o código da moeda de destino (por exemplo, `USD` ou `EUR`). As cotações são fixas e estão no arquivo `rates.json`.
